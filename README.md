# App de Registro de Pedidos

Aplicativo Android desenvolvido para registrar pedidos de clientes de uma lanchonete, com uso em eventos ou pontos físicos. O app permite ao cliente selecionar um lanche, inserir seu nome e visualizar um resumo do pedido.

---

## 🏗️ **Tecnologias Utilizadas**
- **Linguagem:** Java
- **IDE:** Android Studio
- **Interface:** XML

---

  ## 🏗️ Funcionalidades:
- **Tela de Boas-Vindas**: Exibe a logomarca da lanchonete e um botão para iniciar o pedido.
- **Formulário de Pedido**: Permite selecionar o tipo de lanche e inserir o nome do cliente.
- **Resumo do Pedido**: Mostra o nome do cliente e o lanche escolhido, com imagem decorativa e botão para novo pedido.
